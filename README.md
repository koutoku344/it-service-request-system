# IT Service Request System

ITサービス申請システムを題材に、以下の順序でインフラおよびアプリケーションを構築する学習プロジェクトです。

1. Terraformを使用したAWS環境構築
2. 同等構成のオンプレミス環境構築
3. AWSとオンプレミスを連携したハイブリッド環境構築
4. アーキテクト観点の設計・技術文書作成
